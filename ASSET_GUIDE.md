# Asset Guide

Use `public/media` for images, videos, and PDFs that are referenced by URL strings in portfolio data or opened directly in a browser tab.

Current public media folders:

- `public/media/backgrounds/` - full-page background images used from CSS.
- `public/media/hero-roles/` - rotating hero role images.
- `public/media/experience/wso2/gallery/` - WSO2 gallery photos.
- `public/media/experience/wso2/navigation/` - SLAM, map, navigation, and path-planning outputs.
- `public/media/experience/wso2/architecture/` - architecture diagrams.
- `public/media/experience/wso2/robot/` - Unitree Go2 and robotic-arm images.
- `public/media/placeholders/` - generic placeholder images.

Use `src/assets` for images and icons imported directly by React components, such as skill icons, education images, and local section background images.

Use `asset-inbox/` only for original raw files before converting, resizing, or naming them for the site. This folder is ignored by git and is not part of the deployed website.
