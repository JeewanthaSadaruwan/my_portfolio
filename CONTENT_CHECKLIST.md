# Portfolio Content Checklist

Supply these items before publishing:

- Full name
- Professional title
- Short biography
- Profile photograph
- Email address
- GitHub profile
- LinkedIn profile
- Resume PDF
- Skills
- Technologies
- Experience entries
- Education details
- Certifications
- Projects
- Project screenshots
- Project GitHub links
- Project live-demo links
- Achievements
- Leadership or community activities
- Contact-form preference
- Domain name
- Open Graph preview image
- Sitemap and canonical URL
